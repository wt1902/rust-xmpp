# 0.8.1

- Исправлена задержка доставки MUC с растущим архивом: после каждого сообщения
  больше не выполняется полный scan/rewrite архива для expiry. Очистка остаётся
  в maintenance и перед MAM-запросами; append и crash checkpoint до fanout сохранены.
- Неизменённые native config/persistent index не перезаписываются при каждом
  сообщении. Удалённые файлы восстанавливаются, ошибки экспорта повторяются.
- CSI больше не сохраняет SM snapshot при отсутствии изменения durable очереди.
  Изменённая очередь сохраняется до отправки; при ошибке записи очередь откатывается.
- Личные сообщения, IQ и входящая федерация к аккаунтам больше не захватывают
  общий MUC mutex, ожидая несвязанную работу с комнатными архивами.
- Добавлены регрессии native exports/archive scanning/CSI rollback и реальный
  TLS latency check в verify-local.sh, автоматически включённый и в CI.

Измерения и границы подтверждения: [docs/MESSAGE-LATENCY.md](docs/MESSAGE-LATENCY.md).
Результаты итогового прогона: [docs/VALIDATION-0.8.1.md](docs/VALIDATION-0.8.1.md).
